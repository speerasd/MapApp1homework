# MapApp

## Лабораторная 1

## Запуск на устройстве

1. Установите зависимости

   ```bash
   npm install
   ```

2. Запустите приложение

   ```bash
   npx expo start
   ```

## Решения при реализации

1. Context API для глобального состояния маркеров и изображений
2. Маршрутизация через expo-router
3. Компонентный подход


## Дополнительные функции

1. Редактирование данных о маркеров через вызов модального окна
2. Переключение между картой и списком маркеров
3. Переход и с карты и со списка к деталям маркеров
4. Удаление маркеров

## Ограничения и проблемы

1. Карты не работают в веб версии
2. Для работы с изображениями требуется разрешения к галереи
3. Маркеры сохраняются только в памяти и при перезапуске приложения исчезают
4. Изображения также сохраняются только в локально
5. Нет поиска по маркерам
6. Кнопка для переключения между списком маркеров и картой может мешать редактированию или удалению первого маркера

## Документация схемы базы данных
1. Markers
   1. id - уникальный идентификатор метки
   2. latitude - широта местоположения
   3. longitude - долгота местоположения
   4. title - название метки
   5. description - описание метки

3. Marker_images
   1.   id - уникальный идентификатор изображения
   2.   uri - URI изображения в файловой системе
   3.   marker_id - внешний ключ к таблице markers
   4.   createAt - дата добавления изображения
   5.   width - ширина изображения
   6.   height - высота изображения

## Обработка ошибок
1. Ошибки инициализации SQLit
2. Ошибки выполнения SQL-запросов

## Инструкция по тестированию

1. Скачайте fake GPS
2. Включите функцию фиктивного местоположения
3. Создайте метку
4. Войдите в радиус метки(100м и ближе) -> получите уведомление
5. Выйдите из радиуса метки, уведомление пропадет и при вхождении в радиус метки снова появится
6. Подождите около метки 5 минут, уведомление придет снова


## Описание стратегии управления уведомлениями

1. Интеллектуальный показ уведомлений - При вхождении в радиус метки уведомление показывается, при выходе из радиуса уведомление скрывается, а также удаляется из памяти
2. Защита от спама - Уведомление показывается при вхождении в радиус метки и вызывается каждые 5 минут для напоминания пользователю
3. Энергоэффективное отслеживание - Системный тротлинг составляет или 5 метров или 5 минут, а также прикладной тротлинг для проверки рядом с нахождением метки раз в 2 секунды
4. Управление состоянием уведомлений - Для отслеживания активных уведомлений используется Map включающий в себя id уведомления, время создания, а также id маркера для которого это уведомление было создано

## Известные ограничения

1. Оптимальное количество меток +- 10-20 штук
2. Частота проверки раз в 2 секунды
3. Увеличенное потребление батареи за счет постоянного отслеживания GPS
4. Ограничение точности в +- 5-20 метров
5. При создании метки на пользователе(в радиусе метки) для инициализации метки нужно 5-10 секунд
