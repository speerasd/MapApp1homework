# MapApp

##Лабораторная 1

## Запуск на устройстве

1. Установите зависимости

   ```bash
   npm install
   ```

2. Запустите приложение

   ```bash
   npx expo start
   ```

## Решения при реализации

1. Context API для глобального состояния маркеров и изображений
2. Маршрутизация через expo-router
3. Компонентный подход


## Дополнительные функции

1. Редактирование данных о маркеров через вызов модального окна
2. Переключение между картой и списком маркеров
3. Переход и с карты и со списка к деталям маркеров
4. Удаление маркеров

## Ограничения и проблемы

1. Карты не работают в веб версии
2. Для работы с изображениями требуется разрешения к галереи
3. Маркеры сохраняются только в памяти и при перезапуске приложения исчезают
4. Изображения также сохраняются только в локально
5. Нет поиска по маркерам
6. Кнопка для переключения между списком маркеров и картой может мешать редактированию или удалению первого маркера


##Документация схемы базы данных
1. Markers
   1. id - уникальный идентификатор метки
   2. latitude - широта местоположения
   3. longitude - долгота местоположения
   4. title - название метки
   5. description - описание метки

3. Marker_images
   1.   id - уникальный идентификатор изображения
   2.   uri - URI изображения в файловой системе
   3.   marker_id - внешний ключ к таблице markers
   4.   createAt - дата добавления изображения
   5.   width - ширина изображения
   6.   height - высота изображения
